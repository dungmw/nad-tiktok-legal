Privacy Policy

Last updated: September 2026

Nad Tiktok Manager ("the Tool") is an internal application used solely by its owning organization to manage its own TikTok accounts. This policy explains what data the Tool accesses and how it is used.

1. Data We Access

When a TikTok account is connected via TikTok's official OAuth login, the Tool accesses only the data covered by the scopes explicitly granted at authorization time, which may include: basic profile information (username, avatar, display name), and the ability to upload and publish video content on behalf of the connected account.

2. How Data Is Used

Data accessed through TikTok's API is used exclusively to operate the Tool's core function: scheduling and publishing content to the connected TikTok account(s), and displaying basic account/post information within the Tool's dashboard.

3. Data Storage

Access tokens and account data are stored securely on infrastructure controlled by the organization operating this Tool, and are not shared with third parties except as required to operate the Tool (e.g. TikTok's own API).

4. Data Retention & Deletion

Data is retained for as long as the TikTok account remains connected to the Tool. Disconnecting an account removes its stored access tokens. Users may request full data deletion by contacting the organization operating this Tool.

5. No Third-Party Sharing

We do not sell or share user data with third parties for advertising or marketing purposes.

6. Contact

For privacy questions or data deletion requests, contact the organization operating this Tool.
